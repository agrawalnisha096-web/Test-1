Before the first dollar: 4 things must be live

  • Conversions in GA4: signup, demo booked and first API key created. GA4 is collecting, but today only app downloads count as conversions, and Nautili visits also land in DevZero's GA4
  • Google Ads conversion tag and remarketing audience through GTM, so even unconverted clicks build a retargeting list
  • Landing pages: the Claude Code cost calculator, /compare/litellm (404 today) and the homepage retitle. Ads to a page that doesn't match the query waste the budget
  • Mirror domains redirected (nautili.dev, nautir.ai), so ad clicks and organic links consolidate on nautili.ai

How to run it

  • Weeks 1–2: Maximize Clicks with a CPC cap ($6 on coding cost, $25 on competitors, $30 on category). Learn which terms convert
  • Weeks 3–6: move to Maximize Conversions once a campaign has ~30 conversions; pause keywords with 0 signups after $150 spend
  • Month 2: add UK, Canada, Germany and India (coding-cost terms are $1–2 a click in India)
  • Competitor terms: bid on rival names as keywords, but keep them out of ad text. Trademark complaints get ads disapproved
  • Every week: search-terms review, negatives, ad copy test (2 ads per ad group)
  • Report on: cost per signup and cost per activated workspace, not clicks
