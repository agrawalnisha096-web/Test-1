Tier 1 · the top 10

Goal: Google top 10 for each

  • Fix the blockers first: remove the copied Kubernetes posts, submit the sitemap, retitle the homepage. Until then Google reads Nautili as a Kubernetes site
  • Two of the 10 already have posts that Google crawled but did not index (claude-code-cost, claude-code-proxy). Retitle, add internal links, request indexing in week 1
  • Position around spend control in developer words ('LLM cost', 'cost per developer'); avoid 'AI spend management', where Google shows finance software
  • Build the Claude Code cost calculator: it targets 38,500 searches a month across 'claude code pricing' and 'claude code cost'
  • Provider pages for OpenAI and Anthropic: rename to 'X API Pricing', add a price table and Product/Offer schema
  • Links from devzero.io (DR 61) into the gateway pillar and the compare pages are the fastest authority boost
  • New domain: expect 4–8 months to top 10 for these. AI-coding-cost terms move first because competition is light
Tier 2 · keywords 11–50

Goal: top 50 for all, then top 20

  • API pricing: reuse the 86 provider pages. They need real content first (about 190 words each today), then pricing titles, tables and schema
  • Alternatives: one /compare page per competitor (LiteLLM, Vercel, Cloudflare, Helicone, Kong, Bifrost) plus /alternatives for the top three. 'litellm vs openrouter' and 'openrouter alternative' are rising with difficulty 0
  • Distribution as much as content: ~10 integration pages, provider listings inside coding tools (Cline, Roo Code, Kilo Code, OpenCode, Continue), marketplaces and directories. Rivals like Requesty get ~800 linking sites this way
  • Programmatic model-vs-model pages and a token cost calculator, using the model data Nautili already has
  • AI coding cost: one comparison post (Copilot vs Cursor vs Claude Code vs Codex vs Windsurf) covers 5 keywords
  • Competitor brand terms (litellm, portkey) are top-50 targets; Nautili won't outrank their own sites
  • Month 3 goal: impressions for all 50 in Search Console. Month 6 goal: 15–20 of them in the top 20
